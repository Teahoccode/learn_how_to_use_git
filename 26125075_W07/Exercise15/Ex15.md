Which one of the following is not a possible state for a pointer?
A. Hold the address of the specific object
B. Point one past the end of an object
C. Zero
D. Point to a type

-----------------
Answer: D. Point to a type
The pointer is responsible for holding the address of the specific object so A is correct.
Pointer can stand right after the last element of an array, thus B is correct.
For example:
int a[3] = {10, 20, 30};
int *p = a;         
int *end = a + 3;  

while (p != end) {  
    cout << *p << " ";
    p++;            
    }
The zero state of the pointer is when it doesn't point to any location or nullptr.
A pointer only point to a specific memory location not a type, thus D is incorrect
