Exercise 21
A pointer can be initialized with
A. Null
B. Zero
C. Address of an object of same type
D. All of them
---------
Answer: D. All of them
Explain:
A pointer can be initialized with a null value (NULL or nullptr in modern C++) or 0 (A, B), which means that the pointer hasn't pointed to any memory location yet. Additionally, it can be initialized with the address of an object of the same type (C). For example:
int a = 5;
int *ptr = &a;
int *damn = nullptr;
int *oke = 0;
