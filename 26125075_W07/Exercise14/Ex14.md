Exercise 14
Choose the right option.
string* x, y;
A. x is a pointer to a string, y is a string
B. y is a pointer to a string, x is a string
C. Both x and y are pointers to string types
D. None of the mentioned

--------------
Answer: A. x is a pointer to a string, y is a string
To define a point there would be * before the pointer's name
string *x --> a point
string y --> a string
if want to define two pointers, it would be
string *x, *y;
