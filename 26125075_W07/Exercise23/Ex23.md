A qualifier that enables programmers to inform the compiler that the value of a
particular variable should not be modified?
A. ptr
B. const
C. stsrt
D. None of them
-----------------
Answer: B. const
Explain:
const is the qualifier for user to inform the compiler to 'lock' the value of a particular variable, for example:
const int a = 10; (a can not be modifified)
int *const ptr = &a; (cannot modify the address that the pointer holds)
