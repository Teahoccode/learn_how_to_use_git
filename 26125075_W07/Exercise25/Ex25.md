Exercise 25
Referencing a value through a pointer is called
A. Direct calling
B. Indirection
C. Pointer referencing
D. All of them
--------------------
Answer: B. Indirection
Referencing a value through a pointer is the process of modifying and changing the value stored in a memory location through its pointer. For example:
int a = 10;
int *ptr = &a;
cout << *ptr << "\n"; \\ return 10;

*ptr = 20; 
cout << *ptr << "\n"; \\ return 20 by referencing
