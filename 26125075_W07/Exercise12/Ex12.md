What will be the output of the program?
#include<stdio.h>
int main()
{
char *str;
str = "%d\n";
str++;
str++;
printf(str-2, 300);
return 0;
}

A. No output
B. 30
C. 3
D. 300
---------------
Answer: D. 300
The pointer str pointing to the first element of "%d\n", which is %. 
str++ -> pointer points to d
str++ -> pinter points to \n
str - 2 --> point to %
Thus printf(str-2, 300) is equivalent to printf("%d\n", 300). Therefore, the result is 300s
