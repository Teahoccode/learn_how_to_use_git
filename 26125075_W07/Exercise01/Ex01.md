Answer:

cout << b << endl; 
This line print out the address of variable a, as b is a pointer (int *b) point to the location of variable a

cout << *b << endl;
Output: 3
This line print out the value stored in variable a through deferencing pointer b.

cout << &b << endl;
This line print out the address of pointer b. 

cout << a << endl;
Output: 3
This line print out the value of the variable a (a is a normal variable with integer type)

cout << &a << endl;
This line print out the address of the variable a, which having the same value with b. With '&' indicating the address of a certain variable
