What is the output of this program?

#include <iostream>
using namespace std;
int main()
{
int a = 5, b = 10, c = 15;
int *arr[ ] = {&a, &b, &c};
cout << arr[1];
return 0;
}

A. 5
B. 10
C. 15
D. It will return some random number

Answer: D. It will return some random number
Actually, the program would return the address of an object rather than 'some random number'. Arr[1] is &b which is the address of the memory location named b, thus it would return the address of b.
