Answer:

cout << *p << endl;
Output: 3
When initializing pointer p pointing to the memory location of a, printing *p means deferencing. The line print out the value of the memory location that p points to.

p = new int(5);
cout << *p << endl;
Ouput: 5
The program want to allocate value 5 to a certain memory location that p points to. *p is deferencing and printing out the value stored in that memory

However, because we haven't delete p after cout, it would lead to a memory leak.
