Point out the compile time error in the program given below.
#include<stdio.h>
int main()
{
int *x;
*x=100;
return 0;
}
A. Error: invalid exercise for x
B. Error: suspicious pointer conversion
C. No error
D. None of above

---------------
Answer:C. No error

The line *x = 100 is correct in syntax so there is no problem in the compilation
Howver, when the program runs, the pointer x is declared but it is not an address to point to, mso it holds a trash value. Therefore. writing 100 in that memory location can crash the program, which is unintialized pointer bug.
