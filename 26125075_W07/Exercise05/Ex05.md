What are the last values of *p , q , *r , v and *s ?

1. int v = 8, *r, *s;
2. int *p;
3. int q = 100;
4. p = &q;
5. r = p;
6. *p = 20;
7. p = new int;
8. *r = 30;
9. q = v;
10. s = p;
11. *s = 50;

----------------------
Answer:

The last value of *p is: 50
Explain: First, pointer p points to the memory location of variable q (line 4). Then. it points to location of r and the value of that location is 20 (line 6). Then, p is allocated a new memory location, s points to that location which is later assigned the value of 50 through s (line 11)

The last value of q is: 8
Explain: 
int v = 8, q = 100 --> p = &q, r = p (p and r point to the location of q) --> *p = 20 (q = 20) --> *r = 30 (q = 30) --> q = v (q = 8) 

The last value of *r is: 8
Explain:
r = p (r point to the memory that p point to) --> *p = 20 (*r = 20) --> *r = 30 --> q = v = 8 (as r point to q) thus *r = 8 (Final value)

The last value of v is: 8 
Explain:
First, we initialize v with the value of 8. Through different steps, v still hold the same value and there is no point point to the memory location of v.

The last value of *s is: 50
Explain: as the final value of *p is 50 (represented before), thus s = p (line 10, *s = 50), then *s = 50 (line 11).
