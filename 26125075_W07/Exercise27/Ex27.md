What is a pointer?
A. Pointer contains an address of a variable
B. It's an operator
C. It's a function
D. None of them
----------
Answer: A. Pointer contains an address of a variable
Explain:
The definition of a pointer is a variable that is used to store the address of another variable, for example:
int a = 10;
int *ptr = &a;
cout << ptr; // return the address of the memory location named 'a'
