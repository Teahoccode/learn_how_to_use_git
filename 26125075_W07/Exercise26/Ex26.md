Which unary operator is used for determining the size of an array?
A. sizeof
B. size_array
C. s_array
D. size_ofarray
---------
Answer: A. sizeof
Explain:
The operator sizeof is used for determining the size of the array in bytes, for example:
int a[5] = {1,2,3,4,5};
cout << sizeof(a); // return 20 (bytes), as every integer accounts for 4 bytes
cout << sizeof(a) / sizeof(a[0]); // determining the number of elements in that array
