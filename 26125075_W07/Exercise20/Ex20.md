What is the output of this program?
#include <iostream>
using namespace std;
int main()
{
char *ptr;
char Str[] = "abcdefg";
ptr = Str;
ptr += 5;
cout << ptr;
return 0;
}
A. fg
B. cdef
C. defg
D. abcd
-----------------

Answer: A. fg
Explain: 
ptr = Str | The pointer ptr points to the first element 'a' of the array.
ptr += 5  | The pointer points to the fifth element 'f' of the array.
Thus, when print out ptr, it would print the array of characters beginning from where the point points until it meets the terminating null.
