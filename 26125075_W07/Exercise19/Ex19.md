What is the output of this program?
#include <iostream>
using namespace std;

int main()
{
char arr[20];
int i;
for(i = 0; i < 10; i++){
    *(arr + i) = 65 + i;
}  
*(arr + i) = '\0';
cout << arr;
return(0);
}

A. ABCDEFGHIJ
B. AAAAAAAAAA
C. JJJJJJJJ
D. None of the mentioned
--------------------
Answer: A. ABCDEFGHIJ
Explain:
The program works on the ascii table. In the loop, *(arr+i) = 65 + i í assigning the char value to each element of the array.
*(arr + 0) = arr[0] = A (ascii number of A is 65)
*(arr + 1) = arr[1] = B (ascii number of B is 66)
...
*(arr + 9) = arr[9] = J
Finally, *(arr + i) = '\0', i here is 10. Thus the correct result is ABCDEFGHIJ.
