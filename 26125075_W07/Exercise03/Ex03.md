These lines print about the value stored in the memory location that a and b point to

However, there are some double-free errors:

int *b = new int
We just initialize location for pointer b, and then make b point to the same location that a points to without releasing the old ones to the systems, causing a memory leak.

Another error is that we delete pointer twice:
as b = a
delete a --> releasing the location back to the system
delete b --> deleting that location again, which is invalid!
