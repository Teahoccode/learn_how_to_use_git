What will be the output of the program?
#include<stdio.h>
int main()
{
char str[] = "peace";
char *s = str;
printf("%s\n", s++ +3);
return 0;
}

A. peace
B. eace
C. ace
D. ce

------
Answer: D. ce
Explain:
The pointer point to the first element 'p' of the array.
when printf("%s\n", s++ + 3)
s++ + 3 is equivalent to s = s + 3, it means what the pointer would be jump to index 3 at 'c'
When printing out through pointer, it would print out from where the pointer stands until meeting terminating null.
Thus the result is 'ce'
