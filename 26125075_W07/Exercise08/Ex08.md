#include<stdio.h>
#include<string.h>
int main()

{
int i, n;
char *x="Alice";
n = strlen(x);
*x = x[n];
for(i=0; i<=n; i++)
{
printf("%s ", x);
x++;
}
printf("\n", x);
return 0;
}
What will be the output of the program?
A. Alice
B. ecilA
C. Alice lice ice ce e
D. lice ice ce e

-----------------

Answer: D. lice ice ce e
Explain:
x points to the first character of "Alice". printf("%s ", x) prints from that position until it meets the terminating null.

strlen(x) returns 5, but the string actually has 6 characters (the last one is null). So x[n] is x[5], which is the null character. The line *x = x[n] puts that null into the first position, so the string now starts with null and printing from the beginning gives nothing.

Then the loop moves x one step to the right each time:
loop 1: nothing, loop 2: lice, loop 3: ice, loop 4: ce, loop 5: e, loop 6: nothing.

So the result is D. lice ice ce e
