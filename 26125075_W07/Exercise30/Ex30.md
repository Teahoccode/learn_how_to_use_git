What will be the output of the following program?
#include <iostream>
using namespace std;
int main()
{
int a = 32, *ptr = &a;
char ch = 'A', &cho = ch;
cho += a;
*ptr += ch;
cout << a << ", " << ch << endl;
return 0;
}

A. 32, A
B. 32, a
C. 129, a
D. 129, A
------------------
The final value of ch is 'a'. The ascii number of 'A' is 65, when passing by reference &cho, 65 + 32 = 97, which is equivalent to 'a'. Thus the final value of ch is 'a';
*ptr += ch is equivalent to the value of a + 97 = 129 (ptr is the pointer points to a, altering the value). Thus the value of a is 129.
