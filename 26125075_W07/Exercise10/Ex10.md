What will be the output of the program?
#include<stdio.h>
int main()
{
int i, a[] = {2, 4, 6, 8, 10};
change(a, 5);
for(i=0; i<=4; i++)
printf("%d, ", a[i]);
return 0;
}

void change(int *b, int n)
{
int i;
for(i=0; i<n; i++)
*(b+1) = *(b+i)+5;
}

A. 7, 9, 11, 13, 15
B. 2, 15, 6, 8, 10
C. 2 4 6 8 10
D. 3, 1, -1, -3, -5

---------------------
Answer: B. 2, 15, 6, 8, 10
The loop is responsible for printing out the value of index i of array.
Nevertheless, function change(a, 5) alters the value of the array following the given formats
a[0] = a[0] as the loop only changing value at index 1
Loop
*(a+1) = *(a + 0) + 5 =  7
*(a+1) = *(a + 1) + 5 = 7 + 5 = 14
*(a+1) = *(a + 2) + 5 = 6 + 5 = 11
*(a+1) = *(a + 3) + 5 = 8 + 5 = 13
*(a+1) = *(a + 4) + 5 = 10 + 8 = 15 (end)
