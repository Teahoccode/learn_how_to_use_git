Which of the following is illegal?
A. int *ip;
B. string s, *sp = 0;
C. int i; double* dp = &i;
D. int *pi = 0;
------------------
Answer: C. int i; double *dp = &i;
The pointer must have the same data type when being defined with the object that it points to. In C, though i is of type int, whereas dp is a pointer to double (double*). Directly assigning *int to *double without an explicit type cast would result in a compilation error.
